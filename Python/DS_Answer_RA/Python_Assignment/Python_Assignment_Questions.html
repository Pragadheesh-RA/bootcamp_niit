Python Programming Assignments

Instructions: Write clean, readable Python code for each question. Add comments where necessary and test your programs with multiple inputs.

1. Python Fundamentals, Variables, Data Types, Operators, Control Flow

  1. Write a program to accept a student's name, age, department, and percentage and display them in a formatted output.
  2. Write a program to convert a temperature from Celsius to Fahrenheit and Fahrenheit to Celsius.
  3. Create a program that accepts two numbers and demonstrates arithmetic, comparison, logical, assignment, and membership operators.
  4. Write a program to check whether a given number is positive, negative, or zero and whether it is even or odd.
  5. Write a program to calculate the grade of a student using if/elif/else based on the percentage.
  6. Write a program to print all numbers from 1 to N using a for loop and calculate their sum.
  7. Write a program to print the multiplication table of a given number using a loop.
  8. Write a program to find the factorial of a number using a while loop.

2. Functions, Modules, Packages, Exception Handling, File Handling

  1. Create a function that accepts three numbers and returns the largest number.
  2. Create a function to check whether a given string is a palindrome.
  3. Create a module named calculator.py containing functions for addition, subtraction, multiplication, and division. Import and use it from another Python file.
  4. Create a package named utilities with separate modules for string operations and number operations. Import functions from the package and demonstrate them.
  5. Write a program that handles ValueError when the user enters non-numeric input.
  6. Write a program using try-except-else-finally to safely divide two numbers and handle division by zero.
  7. Create a text file named students.txt and write details of at least five students into it. Read and display the contents.
  8. Read a text file and count the number of lines, words, and characters in it.
  9. Append a new student record to an existing file without deleting the previous data.

3. OOP - Classes, Objects, Inheritance, Polymorphism

  1. Create a Student class with name, roll number, and marks attributes and a method to display student details.
  2. Create a BankAccount class with deposit(), withdraw(), and display_balance() methods. Prevent withdrawal when the balance is insufficient.
  3. Create an Employee class and derive Manager and Developer classes from it. Demonstrate inheritance.
  4. Create a Shape base class with an area() method and derive Circle, Rectangle, and Triangle classes that override area(). Demonstrate polymorphism.
  5. Create a Vehicle base class and derive Car and Bike classes. Add suitable attributes and methods and demonstrate method overriding.
  6. Create a class that uses a constructor to initialize product information and a method to calculate the total price based on quantity.

4. Data Structures, Algorithms, Collections

  1. Create a list of student marks and find the highest, lowest, average, and number of students who scored above 75.
  2. Remove duplicate values from a list without using set().
  3. Create a dictionary containing employee names and salaries. Find the employee with the highest salary and calculate the average salary.
  4. Count the frequency of each word in a sentence using a dictionary.
  5. Use a tuple to store five coordinates and display each coordinate separately.
  6. Implement a stack using a list with push, pop, peek, and display operations.
  7. Implement a queue using collections.deque with enqueue, dequeue, and display operations.
  8. Implement linear search to find an element in a list and return its position.
  9. Implement binary search on a sorted list.
  10. Implement bubble sort to arrange a list of numbers in ascending order.
  11. Write a program to find the second-largest number in a list without using sort().
  12. Use Counter, defaultdict, or namedtuple from the collections module in a practical example.

5. REST APIs, JSON, Requests Library

  1. Explain the difference between GET, POST, PUT, PATCH, and DELETE HTTP methods and give one practical use case for each.
  2. Create a Python dictionary representing a student and convert it into a JSON string using the json module. Convert it back into a Python object.
  3. Create a JSON file containing details of at least five products and write a Python program to read and display the products.
  4. Using the requests library, send a GET request to https://jsonplaceholder.typicode.com/posts and display the first five posts.
  5. Using the requests library, fetch user data from https://jsonplaceholder.typicode.com/users and display each user's name, email, and city.
  6. Send a POST request to https://jsonplaceholder.typicode.com/posts with a title, body, and userId and display the response.
  7. Write a program that checks the HTTP status code of an API response and handles successful and unsuccessful responses appropriately.
  8. Create a small API client program that accepts a user ID from the keyboard, calls a public REST API, and displays the requested user's information.
  9. Write a program that catches requests.exceptions.RequestException and handles network/API errors gracefully.
